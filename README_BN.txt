MGM ফ্রি স্টার্টার প্রোটোটাইপ

ফাইলগুলো:
- index.html: সাইটের কাঠামো
- style.css: ডিজাইন
- script.js: মেনুর ডেমো আচরণ
- supabase_schema.sql: Supabase-এ শুরুর জন্য সীমিত স্কিমা

শুরু:
১) index.html ব্রাউজারে খুলে ডিজাইন দেখো, অথবা CodePen-এ HTML/CSS/JS আলাদা বক্সে বসাও।
২) Supabase ব্যবহার করলে SQL Editor-এ স্কিমা পড়ে তারপর চালাও।
৩) RLS ঠিকভাবে যাচাই না করে ব্যক্তিগত তথ্য প্রকাশ কোরো না।
৪) service_role/secret key কখনো frontend-এ দেবে না।
৫) এই ফাইলে বাস্তব লগইন, নিরাপদ API সার্ভার, অ্যাডমিন অনুমতি, ওয়ালেট বা bKash/Nagad পেমেন্ট চালু নেই।
৬) বাস্তব টাকা বা ব্যবহারকারীর তথ্য নেওয়ার আগে নিরাপত্তা, গোপনীয়তা, পরিষ্কার নিয়ম ও অনুমোদিত পেমেন্ট ব্যবস্থা দরকার।
এটি শেখার স্টার্টার, সম্পূর্ণ production website নয়।
